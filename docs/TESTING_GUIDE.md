# 测试指南

## 🧪 如何测试插件功能

### 1. 安装插件

1. 确保 `main.js` 和 `manifest.json` 在插件文件夹中
2. 在 Obsidian 中重新加载插件（Ctrl+R 或重启）
3. 在设置中启用 "EditorJS Plugin"

### 2. 打开富文本编辑器

1. 创建或打开一个 Markdown 文件
2. 右键点击编辑器
3. 选择 "打开为富文本" 或使用命令面板

### 3. 测试核心功能

### 4. 测试 Markdown 转换

#### 测试步骤：
1. 在富文本编辑器中创建各种内容
2. 保存并关闭富文本视图
3. 查看 Markdown 源码，确认格式正确
4. 重新打开富文本视图，确认内容完整恢复

#### 应该看到的 Markdown 格式：

```markdown
# 标题 1
## 标题 2

- 列表项 1
  - 嵌套项 1.1
  - 嵌套项 1.2

- [ ] 任务 1
- [x] 任务 2（已完成）

> [!info] Alert 标题
> Alert 内容

<details>
<summary>Toggle 标题</summary>
Toggle 内容
</details>

$$
E=mc^2
$$

[🔘 按钮文本](https://example.com)

这是一段文本[^1]

[^1]: 这是脚注内容
```

### 5. 常见问题排查

#### 问题：插件无法加载
- 检查控制台（Ctrl+Shift+I）是否有错误
- 确认 `main.js` 文件存在且大小约 1.1 MB
- 尝试重启 Obsidian

#### 问题：某个工具不显示
- 打开插件设置，检查该工具是否已启用
- 在设置中的 "启用的工具" 列表中查找

#### 问题：Markdown 转换不正确
- 检查是否有 HTML 注释 `<!-- editorjs-data: ... -->`
- 确认 Markdown 语法符合 Obsidian 规范

#### 问题：快捷键不工作
- 检查是否与其他插件冲突
- 在 Obsidian 设置中查看快捷键配置

### 6. 性能测试

#### 测试大文档性能：
1. 创建包含 50+ 个块的文档
2. 测试滚动流畅度
3. 测试保存速度
4. 测试加载速度

#### 预期性能指标：
- 启动时间：< 1 秒
- 保存时间：< 500ms
- 加载时间：< 1 秒
- 滚动帧率：60 FPS
